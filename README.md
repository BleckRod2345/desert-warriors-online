# Desert Warriors Online — نسخة جماعية للهاتف

هذه نسخة أولية قابلة للتشغيل من لعبة ساحة معركة متعددة اللاعبين عبر WebSocket. الواجهة مصممة للهاتف، والخادم يدير اللاعبين والطلقات والإصابات والذخيرة.

## المتطلبات
- Node.js 18 أو أحدث
- اتصال إنترنت عند الاستضافة
- استضافة تدعم تطبيقات Node.js وWebSocket للعب بين الهواتف عبر الإنترنت

## التشغيل على الكمبيوتر للتجربة
1. فك ضغط الملف.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   ```bash
   npm install
   npm start
   ```
4. افتح `http://localhost:3000` في المتصفح.
5. لتجربة لاعبين على نفس شبكة Wi‑Fi، افتح عنوان IP المحلي للكمبيوتر من الهاتف، مثل `http://192.168.1.20:3000` (استبدل العنوان بعنوان جهازك).

## اللعب عبر الإنترنت من أماكن مختلفة
1. ارفع محتويات هذا المجلد إلى خدمة استضافة تدعم Node.js وWebSocket.
2. شغّل `npm install` ثم `npm start` وفق تعليمات الاستضافة.
3. استخدم رابط HTTPS الذي توفره الاستضافة. إذا كانت اللعبة مفتوحة عبر HTTPS، يجب أن يستخدم اتصال WebSocket `wss://`.
4. افتح اللعبة على الهاتف، اكتب رابط WebSocket في خانة «عنوان الخادم» إذا لزم الأمر، ثم أدخل اسمك واضغط «دخول ساحة المعركة».
5. يجب على جميع اللاعبين الاتصال بعنوان الخادم نفسه.

## التحكم
- الأسهم الظاهرة: الحركة.
- اسحب إصبعك على مساحة اللعب لتوجيه التصويب.
- زر «إطلاق»: إطلاق مستمر أثناء الضغط.
- «تلقيم»: إعادة الذخيرة.
- بعد الإقصاء يظهر زر «عودة».

## ملاحظات مهمة
- هذه نسخة تجريبية تعليمية وليست منتجًا تجاريًا جاهزًا أو نسخة مطابقة من Free Fire.
- لا يوجد حسابات مستخدمين أو حفظ تقدم أو حماية متقدمة من الغش حتى الآن.
- يجب استضافة الخادم على خدمة خارجية حتى يعمل اللعب الجماعي بين شبكات مختلفة؛ تشغيل ملف HTML وحده لا يكفي.
- أضف HTTPS/WSS وقيودًا إضافية ومراقبة قبل نشرها لجمهور كبير.
